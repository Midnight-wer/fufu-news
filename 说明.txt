☁️ fufu新闻 — 你的阅读伙伴
================================

欢迎来到 fufu新闻！这是一个可爱的本地新闻聚合器，
帮你把喜欢的 RSS 订阅源汇聚在一起，用 AI 帮你读新闻、打标签。


📖 快速开始
-----------

1. 双击「启动.bat」，fufu 会自动检查环境、安装依赖、启动服务
2. 浏览器打开 http://localhost:3000
3. 使用默认账户登录：fufu / fufu123
4. 添加订阅源 → 等待抓取 → 开始阅读！

后端 API 单独跑在 http://localhost:8800 （前端通过 Vite 代理访问）。

公网版是「只读资讯站」，每天可直接用域名访问，
支持首页新闻列表、新闻详情、分类导航、热门榜单（日/周/月）、站内搜索，
并做了响应式适配与基础 SEO（canonical / Open Graph / robots.txt / sitemap.xml）。

公网版与本地版的区别：
- 公网版只读取静态快照 fufu-web/public/data/news.json，不需要后端和 API Key
- 公网版不提供登录、AI 摘要/对话、收藏、稍后读、评论与阅读上报
- 公网版刷新页面不会 404（使用 HashRouter，#/article/123 形式）

更新公网新闻（内容更新后重新发布）：

  # 1. 从本地数据库导出新的公开快照
  cd fufu-server
  .\.venv\Scripts\python.exe scripts/export_static_snapshot.py

  # 2. 构建并重新部署
  cd ..\fufu-web
  npm run build:static

部署方式与本地开发互不影响：本地仍可继续用「启动.bat」跑完整全栈版。

手动启动：
  # 后端
  cd fufu-server
  python -m uvicorn app.main:app --port 8800

  # 前端
  cd fufu-web
  npm run dev          # → http://localhost:3000


🔧 需要什么环境？
-----------------

- Python 3.10 或更高版本
- Node.js 18 或更高版本
- Windows 10/11（Mac/Linux 也可手动启动）


📡 添加新闻源
-------------

1. 点击左侧「订阅源」
2. 点击「添加订阅」
3. 填入名称和 RSS 地址（或网页 URL）
4. 点击「✨ 添加」

也支持 OPML 导入：点击「导入」按钮，选择 .opml 文件即可
一键搬家，超方便～


🤖 AI 小伙伴
-------------

fufu 内置了 AI 大脑，可以：
- 自动生成新闻摘要（💡 fufu帮你读）
- 自动提取关键词标签
- 陪你聊天（右下角看板娘 · 流式输出）

在「小设置」里配置 AI 后端：
- DeepSeek / Moonshot / OpenAI 兼容 API
- Ollama 本地模型（免费隐私）

注意：一旦填写了自定义 base_url，就必须同时填自己的 api_key ——
服务端不会把自己的 Key 用于陌生地址。


📂 文件和位置
-------------

所有数据都在 D:\fufu新闻\ 下面：
- fufu-server/          Python 后端（FastAPI + SQLAlchemy，端口 8800）
- fufu-web/             前端（Vite + React 18 + TypeScript，端口 3000）
- data/                 SQLite 数据库和日志
- logs/                 运行日志
- launch.py             全平台一键启动脚本
- 启动.bat              Windows 启动入口
- 排查优化报告.md        最近一轮排查/修复/实装的完整记录
- 说明.txt              你正在读的这个文件 :)


📊 分类体系
-----------

源按 folder / AI 标签归入：动漫 · 游戏 · 科技 · 设计 · 综合
首页分类按钮上的数字是**全库真实统计**（接口 /api/v1/articles/categories），
不是当前页的条数。


💛 常用操作
-----------

- 收藏文章：点星星 ⭐
- 稍后阅读：点书签 🔖
- 表态投票：文章底部「你怎么看？」支持 / 反对 / 中立（再点一次可撤票）
- 朗读文章：点「念给我听 📖」（需要浏览器支持）
- 搜索文章：左侧「搜一搜」，支持中文分词全文检索
- Ctrl/Cmd + K：快速跳到搜索页
- 修改密码：暂时需要手动改 .env 文件
- 数据备份：复制 data/ 文件夹即可


🛑 停止服务
-----------

关闭命令行窗口即可。
