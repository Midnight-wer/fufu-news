☁️ fufu新闻 — 你的阅读伙伴
================================

欢迎来到 fufu新闻！这是一个可爱的本地新闻聚合器，
帮你把喜欢的 RSS 订阅源汇聚在一起，用 AI 帮你读新闻、打标签。


📖 快速开始
-----------

1. 双击「启动.bat」，fufu 会自动检查环境、安装依赖、启动服务
2. 浏览器会自动打开 http://localhost:8000
3. 使用默认账户登录：fufu / fufu123
4. 添加订阅源 → 等待抓取 → 开始阅读！

新版 Next.js 前端开发：
  npm install        # 首次运行安装依赖
  npm run dev        # 启动开发服务器 → http://localhost:3000


🔧 需要什么环境？
-----------------

- Python 3.10 或更高版本
- Node.js 18 或更高版本
- Windows 10/11（Mac/Linux 也可手动启动）


📡 添加新闻源
-------------

1. 点击左侧「订阅源」
2. 点击「添加订阅」
3. 填入名称和 RSS 地址（或网页 URL）
4. 点击「✨ 添加」

也支持 OPML 导入：点击「导入」按钮，选择 .opml 文件即可
一键搬家，超方便～


🤖 AI 小伙伴
-------------

fufu 内置了 AI 大脑，可以：
- 自动生成新闻摘要（💡 fufu帮你读）
- 自动提取关键词标签

在「小设置」里配置 AI 后端：
- Ollama 本地模型（推荐，免费隐私）
- 或任意 OpenAI 兼容的 API

如果没有配置 AI，抓取功能依然完全可用哦～


📂 文件和位置
-------------

所有数据都在 D:\fufu新闻\ 下面：
- fufu-server/          Python 后端服务（FastAPI, 端口 8000）
- app/                  Next.js 前端页面（App Router）
- components/           React UI 组件库
- lib/                  核心工具库（订阅源、健康检测、数据模型）
- fufu-web-legacy/      旧版前端（Vite + React，仅供参考）
- data/                 数据库和日志文件（SQLite）
- launch.py             全平台一键启动脚本
- 启动.bat              Windows 启动入口
- package.json          Node.js 依赖配置
- 说明.txt              你正在读的这个文件 :)

💛 常用操作
-----------

- 收藏文章：点星星 ⭐
- 稍后阅读：点书签 🔖
- 朗读文章：点「念给我听 📖」（需要浏览器支持）
- 搜索文章：左侧「搜一搜」，使用中文关键词
- 修改密码：暂时需要手动改 .env 文件
- 数据备份：复制 data/ 文件夹即可
- 侧边栏分类可点击展开/折叠，子分类可独立筛选


🛑 停止服务
-----------

关闭命令行窗口即可。
